# Inspection Drone France

Site vitrine HTML/CSS/PHP (Bron · Lyon · Métropole de Lyon).

- Lancer en local : `php -S localhost:8000`
- Coordonnées et domaine : `includes/config.php` (adapter aussi `robots.txt` et `sitemap.xml` au domaine final)
- Images : illustrations SVG originales dans `assets/img/` (libres de droits), à remplacer par de vraies photos de missions ; remplacer aussi `logo.svg` par le logo officiel.
- Mentions légales : compléter l'hébergeur et le SIRET dès disponibles.
